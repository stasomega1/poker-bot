# poker-bot

Телеграм-бот для учета покерных игр и расчета итогов.

## Переменные окружения

Перед запуском заполните `.env`:

- `BOT_TOKEN` — токен Telegram-бота
- `MONGODB_URI` — строка подключения к MongoDB
- `MONGODB_DB` — имя базы данных, по умолчанию `poker_bot`
- `DEFAULT_BUYIN_PRICE` — цена бай-ина по умолчанию, по умолчанию `2000`
- `REGISTRAR_USER_ID` — `telegram user id` пользователя, который может вызывать `/reg`
- `OPENAI_API_KEY` или `OPEN_API_KEY` — ключ OpenAI для распознавания чеков через `/bill`
- `OPENAI_RECEIPT_MODEL` — модель OpenAI для распознавания чеков, по умолчанию `gpt-4.1-mini`

Если OpenAI-ключ не указан:

- `/bill` с OCR работать не будет
- `/debug` для тестового счета продолжит работать

## Команды

- `/start` `/help` — показать справку
- `/reg` — зарегистрировать группу для игр
- `/game` — сохранить игру из цепочки reply-сообщений
- `/setbuyin 2500` — изменить цену бай-ина для группы
- `/bill` — отправить фото чека с подписью `/bill` или `/bill @payer`
- `/debug` — создать тестовый счет без OCR
- `/history` — показать последние игры текущей группы
- `/stats` — показать краткую статистику текущей группы
- `/players` — показать статистику игроков текущей группы
- `/groups` — показать доступные игровые группы в личке
- `/archive` — показать сообщение о переносе архива в обычную статистику

## Расширенные команды статистики

- `/stats_history` — показать всю историю игр группы
- `/stats_stats` — показать статистику группы
- `/stats_players` — показать расширенную статистику игроков
- `/stats_game <номер>` — показать конкретную игру
- `/stats_player <имя>` — показать статистику и историю игрока
- `/stats_top` — показать топ игроков по выбранному параметру

Также поддерживаются кликабельные alias-команды:

- `/stats_game_54`
- `/stats_player_anelya`

## Пример использования

1. Зарегистрируйте группу:

```text
/reg
```

2. Отправьте сообщение с бай-инами:

```text
Стас 4
Адильхан 1
Игорь 3
Анеля 3
Даник 4
Хамбар 6
Жаник 10
Тима 11
Салта 5
```

3. Ответом на него отправьте сообщение с результатами:

```text
Игорь 26
Жаник 21
```

4. Ответом на сообщение с результатами отправьте:

```text
/game
```

5. Посмотрите историю и статистику:

```text
/history
/stats
/players
```

## Расчет счета

1. Отправьте фото чека с подписью:

```text
/bill
```

или укажите плательщика сразу:

```text
/bill @stasninja
```

2. Бот распознает чек и создаст одно общее сообщение со списком позиций и кнопками `-` / `+`.

3. Участники распределяют позиции кнопками.

4. Что делает бот:

- показывает общий счет в группе
- обновляет распределение в реальном времени
- позволяет отправить человеку его текущий счет в личку кнопкой
- позволяет закрыть или отменить счет кнопками
- после закрытия показывает, кто сколько должен перевести плательщику

## Личные сообщения

В личке бот поддерживает:

- `/start`
- `/help`
- `/groups`
- `/stats`
- `/history`
- `/players`
- `/archive`
- `/stats_history`
- `/stats_stats`
- `/stats_players`
- `/stats_game <номер>`
- `/stats_player <имя>`
- `/stats_top`

Если пользователь состоит в нескольких игровых группах, бот предлагает выбрать группу кнопками.

Для `/stats_player` выбор группы показывается только если указанный игрок найден больше чем в одной доступной группе.
