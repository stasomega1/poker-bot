# pocker-bot

## Телеграм-бот для учета покерных игр и расчета итогов.
#### Навайбкожено за вечер во время просмотра подземелий чикен карри

## Команды

- `/reg` — зарегистрировать чат для работы бота
- `/game` — сохранить игру из цепочки reply-сообщений
- `/setbuyin 2500` — изменить стоимость байина для текущего чата (по умолчанию 2000)
- `/history` — показать последние сохраненные игры
- `/stats` — показать общую статистику по чату
- `/players` — показать статистику по игрокам
- `/help` — показать справку

## Пример использования

1. Зарегистрируйте чат командой:

```text
/reg
```

2. Отправьте сообщение с байинами:

```text
Стас 4
Адильхан 1
Игорь 3
```

3. Ответом на него отправьте сообщение с результатами победителей:

```text
Игорь 8
```

4. Ответом на сообщение с результатами отправьте:

```text
/game
```

5. Посмотрите историю и статистику:

```text
/history
/stats
/players
```
