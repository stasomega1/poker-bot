# poker-bot

## Телеграм-бот для учета покерных игр и расчета итогов.
#### Навайбкожено за вечер во время просмотра подземелий чикен карри

## Команды

- `/reg` — зарегистрировать группу
- `/game` — сохранить игру из цепочки reply-сообщений
- `/setbuyin 2500` — изменить цену бай-ина для группы
- `/history` — показать историю игр текущей группы
- `/stats` — показать статистику текущей группы
- `/players` — показать статистику игроков текущей группы
- `/groups` — показать список доступных игровых групп в личке
- `/archive` — показать команды архива
- `/help` — показать справку

## Команды архива

- `/archive` — справка по архиву
- `/archive_history` — показать все архивные игры
- `/archive_stats` — показать статистику архива
- `/archive_players` — показать статистику игроков архива
- `/archive_game <номер>` — показать архивную игру
- `/archive_player <имя>` — показать статистику и историю игрока
- `/archive_top` — показать топ-10 игроков по выбранному параметру

## Пример использования

1. Зарегистрируйте группу:

```text
/reg
```

2. Отправьте сообщение с бай-инами:

```text
Стас 4
Адильхан 1
Игорь 3
Анеля 3
```

3. Ответом на него отправьте сообщение с результатами:

```text
Игорь 8
Анеля 3
```

4. Ответом на сообщение с результатами отправьте:

```text
/game
```

5. Посмотрите историю и статистику:

```text
/history
/stats
/players
```

## Пример работы с архивом

```text
/archive
/archive_history
/archive_stats
/archive_players
/archive_game 54
/archive_player Стас
/archive_top
```

## Личные сообщения

В личке бот поддерживает:

- `/start`
- `/help`
- `/groups`
- `/stats`
- `/history`
- `/players`
- `/archive`

Если пользователь состоит в нескольких игровых группах, бот предложит выбрать группу кнопками.
